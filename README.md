# Choosing an AI model for ad creative

A model-agnostic way to pick an AI image or video model for ads, and a three-prompt test you can re-run every time a new model ships.

**Read it:** https://clear-cortex.github.io/ai-ad-creative-models/

## The short version

| Axis | Matters for ads? |
|---|---|
| Fidelity per frame | Least: every current model clears the bar |
| Consistency across a set | Most: decides whether you can run a campaign |
| Physics under motion | Situational: product demos, yes; talking heads, no |
| Cost per usable output | Most: price ÷ the share you'd actually run |

Then: three fixed prompts, ten generations each, count what you'd ship. Re-run when something launches; don't switch on the announcement.

Maintained by [Clear Cortex](https://clear-cortex.com), an AI image and video studio for marketing teams. Corrections welcome as issues or PRs.
